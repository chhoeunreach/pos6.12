# ឯកសារពិពណ៌នាប្រព័ន្ធ Loan Management សម្រាប់រៀបចំសម្រង់តម្លៃជូនអតិថិជន

## 1. សេចក្តីសង្ខេប

ប្រព័ន្ធ **Loan Management** គឺជាប្រព័ន្ធគ្រប់គ្រងការលក់បង់រំលស់ និងកម្ចីសម្រាប់អាជីវកម្ម ដែលអាចប្រើប្រាស់ជាមួយទិន្នន័យពី Ultimate POS និងមានមុខងារគ្រប់គ្រងអតិថិជន កម្ចី កាលវិភាគបង់ប្រាក់ ការទូទាត់ ការតាមដានការប្រមូលប្រាក់ របាយការណ៍ និងការផ្ញើសារទៅអតិថិជនតាម Chat/Telegram។

គោលបំណងនៃឯកសារនេះ គឺរៀបចំព័ត៌មានលម្អិតអំពីប្រព័ន្ធ និងមុខងារដែលអាចយកទៅប្រើសម្រាប់ធ្វើ **សម្រង់តម្លៃ / Quotation** ជូនអតិថិជន។

## 2. គោលបំណងប្រព័ន្ធ

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងសម្រាប់:

- គ្រប់គ្រងការលក់ទំនិញបង់រំលស់។
- គ្រប់គ្រងព័ត៌មានអតិថិជន។
- បង្កើតកម្ចីថ្មីពីទំនិញ ឬពីការលក់ក្នុង POS។
- គណនាការបង់រំលស់ប្រចាំថ្ងៃ ប្រចាំសប្តាហ៍ ឬប្រចាំខែ។
- គ្រប់គ្រងកាលវិភាគបង់ប្រាក់។
- កត់ត្រាការទូទាត់របស់អតិថិជន។
- ផ្ញើវិក្កយបត្រ ឬរូបភាពវិក្កយបត្រទៅអតិថិជន។
- តាមដានអតិថិជនហួសកំណត់ និងការចុះជួបអតិថិជន។
- បង្កើតរបាយការណ៍ប្រចាំថ្ងៃ ប្រចាំខែ និងប្រចាំឆ្នាំ។
- ផ្តល់ផ្ទាំងគ្រប់គ្រងសម្រាប់អតិថិជនមើលព័ត៌មានផ្ទាល់ខ្លួន។
